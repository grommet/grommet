## TimeInput

TimeInput is a segmented, keyboard accessible time selection component with optional 12-hour or 24-hour formatting.

### Features

- Segmented keyboard editing for hours, minutes, seconds, and AM/PM
- Popup selection for each time section
- Controlled and uncontrolled value modes
- Form and FormField integration
- Screen reader announcements for active section and picker state

### Basic

```jsx
<TimeInput format="12" defaultValue="12:34:56 PM" />
```
